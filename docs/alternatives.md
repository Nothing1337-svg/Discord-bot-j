# Исследование платформ и похожих ботов

Дата: 22 сентября 2026. Российские сервисы исключены из набора интеграций и рекомендаций.
Проверены официальные документы и сайты. Полная реализованная матрица — [platforms.md](platforms.md).

## Похожие боты

| Решение | Официально заявленное назначение | Отличие проекта |
|---|---|---|
| [MonitoRSS](https://docs.monitorss.xyz/) | Передача RSS в Discord | Здесь также есть отдельные API-адаптеры, SQLite, slash-команды и свой хостинг |
| [Pingcord](https://pingcord.xyz/) | Уведомления нескольких платформ, в том числе YouTube/Twitch/TikTok | Здесь явные credentials владельца, нет обещания доступа к любому аккаунту |
| [Noti](https://noti.bot/) | Уведомления видео и live с нескольких платформ | Здесь только публикации видео, без отдельного мониторинга старта live |

Это сравнение заявленных функций, а не независимое измерение задержек, тарифов или стабильности.
Наличие интеграции в коммерческом боте не доказывает наличие открытого API для любого разработчика.

## Что изучено, но не объявляется поддержанным

| Платформа / сценарий | Что установлено и почему не включено |
|---|---|
| Dailymotion | Текущая [API v2](https://developers.dailymotion.com/docs/welcome) использует OAuth Bearer; есть [список видео профиля](https://developers.dailymotion.com/reference/list-profile-videos). В этой версии адаптер не реализован; старый anonymous endpoint не выдаётся за проверенную интеграцию |
| X | Есть [GET user posts](https://docs.x.com/x-api/users/get-posts), но это лента постов: нужен собственный доступ API, фильтрация видео и проверка текущих лимитов аккаунта. Встроенного адаптера нет |
| Kick | [Официальная документация](https://github.com/KickEngineering/KickDevDocs/blob/main/apis/livestreams.md) описывает livestream endpoints. Live-событие не равнозначно новому опубликованному ролику; адаптер видео не реализован |
| Rumble | Универсальный официальный API новых видео произвольного канала в рамках проверки не подтверждён. Поддержка не заявляется |
| Facebook, Snapchat, Pinterest и другие | Не реализованы. Наличие стороннего RSS-моста не считается нативной поддержкой |

Любую **действующую** видеоленту разрешённого внешнего сервиса можно подключить через RSS. Получение доступа,
оплата и стабильность такого сервиса остаются отдельными условиями, а не скрытой частью готового бота.

## Вывод для реализации

Для публичных лент/REST API возможен polling. Для авторизованных аккаунтов нужен реальный OAuth token,
права и иногда App Review. Универсального анонимного интерфейса всех платформ нет. Поэтому в команду
`/subscribe` включены только реально написанные адаптеры; непроверенные варианты перечислены отдельно.
Во всех случаях база сохраняет baseline/очередь/ID, ошибки платформы и Discord повторяются независимо.
