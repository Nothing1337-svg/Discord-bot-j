## Покрытые сценарии

- Baseline без рассылки старых видео, повторные проверки и дедупликация после открытия той же SQLite.
- Неуспешная отправка не помечает видео доставленным, backoff, изоляция источников.
- Лимит отправок, сохранённая очередь при исчезновении видео из ленты, конкурентные проверки без дублей.
- Уникальность подписок, каскадное удаление истории и очереди.
- RSS/Atom, порядок, UTF-8 и emoji, повреждённые ленты, нормализация channel ID/login.
- Twitch OAuth token caching и разбор видео с mock API.
- Запрет приватных адресов и DNS-ответов, HTTP redirect/429, ограничение размера ответа.
- Голосовые/Stage, исключение ботов/AFK, уникальность участников.
- Debounce, cooldown после ошибки, возврат к прежнему значению, изменение во время загрузки.
- PNG, ru/en, большие числа, сложные Unicode-кластеры без падения.
- Валидация обязательных настроек, набор intents и команд, права управляющих команд.
- Формирование Discord embed, запрет упоминаний, отказ отправки без прав.
- Отсутствие server BANNER не вызывает загрузку и не удаляет команды рассылки.

Это локальные автоматические проверки с SQLite и mock Discord/API, а не подтверждение production-запуска.

`/banner_preview`, затем опубликовать новый тестовый ролик на подконтрольном канале.
