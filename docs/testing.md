## Обнаруженное при живых проверках

Изначально Python не находил ни файла, ни каталога доверенных CA; PeerTube выдавал
ClientConnectorCertificateError, системный curl при этом работал. Добавлен certifi и проверяемый TLS context
для платформ и Discord. Проверка сертификата и hostname остаётся включённой (121 доверенный CA в установленном
bundle). После исправления получен успешный ответ YouTube; часть отдельных запросов до/после него завершалась
таймаутами. Это среда с нестабильной доступностью, а не обещание постоянной доступности платформ.

Для федеративных PeerTube-каналов важен полный name@host. Ошибочная попытка найти remote-канал только по
имени на чужом instance вернула 404; запрос с полным идентификатором успешен. Проверены пустой канал и
непустой публичный канал. Адаптер использует предоставленный URL, не угадывает origin instance.

## Что проверено автоматически

- Стабильный baseline, дедупликация после перезапуска, сохранённая очередь и каскадное удаление.
- Независимые повторы получения и доставки; источник недоступен, а сохранённая очередь отправляется;
  Discord недоступен, но новые видео продолжают сохраняться.
- Retry-After, лимит отправок, конкурентные проверки, ограничение размера HTTP и запрет redirects.
- Миграция существующей SQLite без потери истории; старые записи, впервые появившиеся в окне, не
  отправляются для новых подписок при наличии даты публикации.
- YouTube ID/@handle/URL и tabs, разрешение handle через API и отказ без API key.
- Twitch cursor pagination и кеширование app token.
- TikTok pagination, error внутри HTTP 200, видимый лимит страниц, сквозной путь от адаптера до SQLite/доставки.
- Instagram: фильтрация фото/каруселей, только VIDEO; next URL не используется для пересылки bearer token.
- Vimeo: фильтрация private/unlisted/processing видео.
- PeerTube: URL нормализация, запрет внутренних адресов, фильтрация live/private.
- Account aliases, неверный provider, отсутствующий/истёкший token; безопасный вывод doctor.
- Intents, разрешения команд, запрет упоминаний, обработка недостаточных прав канала.
- Голосовой онлайн, AFK/боты/Stage, debounce, cooldown, изменение во время загрузки, недоступный сервер.
- PNG, ru/en, Unicode-графемы и emoji без падения.

Unit-тесты с ответами API не заменяют App Review, OAuth consent и проверку на реальном Discord-сервере.
После настройки нужно добавить подписку на подконтрольного автора, опубликовать **новое** видео и проверить
сообщение. Старые видео специально не отправляются. Для баннера отдельно проверить /banner_preview и
наличие server feature BANNER. Live-старты и пересылка ссылок из сообщений в эту версию не входят.
